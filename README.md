# Synergy2026-4
Практическая работа № 4 
Постановка задачи
Дана драконья стая, состоящая из нескольких драконов. Каждый дракон имеет определённое количество голов. Сила стаи определяется как произведение количества голов всех драконов.

Известно общее количество голов N. Необходимо определить максимальную возможную силу стаи при условии, что у одного дракона может быть не более 7 голов.

Ограничения:

( 0 < N < 100 )
у одного дракона ≤ 7 голов
Цель работы
Разработать алгоритм для определения максимально возможного произведения чисел, сумма которых равна заданному числу N, при ограничении на максимальное значение каждого слагаемого.

Идея решения
Задача сводится к разбиению числа N на слагаемые от 1 до 7 таким образом, чтобы произведение этих слагаемых было максимально возможным.

В рамках данной реализации используется жадный алгоритм, согласно которому:

на каждом шаге выбирается максимально возможное значение (7);
остаток обрабатывается после завершения основного цикла.
Алгоритм решения
Ввести число N.

Инициализировать переменную power = 1.

Пока N > 7:

умножить результат на 7;
уменьшить N на 7.
Умножить результат на оставшееся значение N.

Вывести результат.

Подробное описание выполнения работы
1. Анализ условия
На первом этапе было установлено, что требуется разложить число N на сумму меньших чисел с последующим вычислением их произведения. Ограничение на максимальное значение одного элемента (не более 7) задаёт верхнюю границу разбиения.

2. Выбор подхода к решению
Для решения задачи был выбран жадный подход. Его суть заключается в последовательном выборе максимально возможного допустимого значения (7) для формирования результата.

Такой подход позволяет упростить реализацию алгоритма и сократить количество вычислений.

3. Реализация алгоритма
Программа реализуется следующим образом:

n = int(input())

power = 1

while n > 7:
    power *= 7
    n -= 7

power *= n

print(power)
4. Принцип работы программы
Изначально переменная power инициализируется единицей.
Значение 7 многократно выделяется из общего числа N.
Каждый выделенный элемент участвует в произведении.
После завершения цикла оставшееся значение (≤7) также включается в результат.
5. Пример работы алгоритма
Ввод:
16
Выполнение:
Разбиение:

16 = 7 + 7 + 2
Вычисление:
7 × 7 × 2 = 98
Вывод:
98
6. Анализ корректности решения
Используемый алгоритм является жадным и не гарантирует получение глобально оптимального решения для всех значений N.

Пример ограничения:
N = 8
Жадное разбиение:

7 + 1 → 7 × 1 = 7
Однако существует более выгодный вариант:

4 + 4 → 4 × 4 = 16
Следовательно, жадный алгоритм не всегда обеспечивает максимальный результат.

Вывод
В ходе выполнения кейс-задачи был разработан алгоритм вычисления максимальной силы драконьей стаи при заданном количестве голов.

Реализованный подход основан на жадной стратегии выбора максимального допустимого значения (7), что обеспечивает простоту реализации и высокую скорость выполнения.

При этом установлено, что жадный алгоритм не всегда обеспечивает оптимальный результат. Для получения гарантированно оптимального решения может быть применён метод динамического программирования или полный перебор вариантов разбиения числа.
