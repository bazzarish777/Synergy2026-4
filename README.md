Кейс-задача № 4. Определение максимальной силы драконьей стаи

1. Постановка задачи

Согласно условию, каждый дракон обладает определённым количеством голов, а сила отдельного дракона определяется количеством этих голов. Если в стае находится несколько драконов, то общая сила стаи вычисляется не путём сложения количества голов, а путём перемножения количества голов каждого дракона.

Например, если в стае находятся три дракона, у которых 3, 4 и 5 голов соответственно, то общая сила такой стаи будет равна:

3 × 4 × 5 = 60.

Известно общее количество голов драконьей стаи — натуральное число N, причём 0 < N < 100. При этом у одного дракона может быть не более 7 голов.

Необходимо определить, как следует распределить все имеющиеся головы между драконами, чтобы произведение количества голов каждого дракона было максимально возможным.

Таким образом, задача заключается в поиске такого разбиения числа N на положительные целые числа, каждое из которых не превышает 7, при котором их произведение будет наибольшим.

Проанализировать условие задачи и определить исходные данные.

Установить математическую зависимость между количеством голов и силой стаи.

3. Анализ условия задачи

Для решения задачи необходимо учитывать несколько важных условий.

Первое условие — известно общее количество голов.

Программа получает одно натуральное число N, которое обозначает общее количество голов всей драконьей стаи.

Второе условие — каждый дракон должен иметь положительное количество голов.

При распределении голов нельзя создавать драконов с нулевым количеством голов. Все используемые части разбиения должны быть положительными целыми числами.

Третье условие — у одного дракона не может быть более семи голов.

Каждое число, на которое разбивается N, должно находиться в диапазоне от 1 до 7 включительно.

Четвёртое условие — требуется максимизировать произведение.

Недостаточно просто разделить общее количество голов на произвольные части. Необходимо выбрать такое распределение, при котором произведение всех частей будет наибольшим.

Например, если общее количество голов равно 6, можно рассмотреть следующие варианты:

Один дракон с 6 головами: сила равна 6.

Два дракона с 3 головами каждый: сила равна 3 × 3 = 9.

Три дракона с 2 головами каждый: сила равна 2 × 2 × 2 = 8.

Наибольший результат получается при распределении 6 голов между двумя драконами по 3 головы. Максимальная сила стаи в этом случае равна 9.

Этот пример показывает, что оптимальное распределение голов не обязательно совпадает с распределением, при котором используется минимальное или максимальное количество драконов.

4. Математическое обоснование решения

Чтобы найти максимальное произведение, необходимо определить, какие числа наиболее выгодно использовать при разбиении общего количества голов.

Рассмотрим основные варианты.

4.1. Почему выгодно использовать тройки

Если имеется возможность заменить одну часть, равную 6, двумя частями по 3, произведение увеличивается:

6 < 3 × 3 = 9.

Аналогично, число 7 выгоднее представить в виде 3 и 4:

7 < 3 × 4 = 12.

Число 5 выгоднее разделить на 2 и 3:

5 < 2 × 3 = 6.

Следовательно, части со значениями 5, 6 и 7 в общем случае выгодно преобразовывать в меньшие части, если это увеличивает произведение.

4.2. Почему невыгодно использовать единицы

Число 1 не изменяет произведение:

1 × 3 = 3.

Поэтому при распределении нескольких голов обычно невыгодно оставлять отдельного дракона с одной головой, если эту голову можно объединить с другой частью разбиения и увеличить произведение.

Например, при семи головах распределение 3 + 3 + 1 даёт силу:

3 × 3 × 1 = 9.

Если же распределить головы как 3 + 2 + 2, сила составит:

3 × 2 × 2 = 12.

Таким образом, второй вариант является более выгодным.

4.3. Почему используются двойки и тройки

Для максимизации произведения оптимально использовать преимущественно части, равные 3. Если после распределения остаётся одна или две головы, их необходимо учитывать отдельно.

Если остаток равен 2, используется одна двойка.

Если остаток равен 1, невыгодно оставлять единицу. Вместо этого одну тройку заменяют двумя двойками:

3 + 1 = 2 + 2,

при этом произведение увеличивается:

3 × 1 = 3,

2 × 2 = 4.

Таким образом, оптимальное разбиение числа N строится на использовании троек и двоек.

5. Разработка алгоритма

Для вычисления максимальной силы стаи используется следующий алгоритм.

Шаг 1. Ввод данных.

Считывается число N — общее количество голов драконьей стаи.

Шаг 2. Обработка особого случая.

Если N = 1, максимальная сила равна 1, поскольку имеется только одна голова. В этом случае программа сразу выводит результат.

Шаг 3. Определение остатка от деления на 3.

Вычисляется остаток N % 3. Он показывает, сколько голов останется после распределения максимально возможного количества троек.

В зависимости от остатка алгоритм выбирает один из трёх вариантов:

Если остаток равен 0, всё число разбивается на тройки.

Если остаток равен 1, используется произведение двух двоек и необходимого количества троек.

Если остаток равен 2, используется одна двойка и необходимое количество троек.

Шаг 4. Вычисление произведения.

Переменная power первоначально получает значение 1, 2 или 4 в зависимости от выбранного варианта. Затем в цикле она последовательно умножается на 3 для каждой оставшейся тройки.

Шаг 5. Вывод результата.

После завершения вычислений программа выводит максимальную возможную силу драконьей стаи.

6. Реализация программы на языке C++

Для реализации алгоритма используется язык программирования C++. Программа принимает число N, анализирует остаток от деления на 3, вычисляет оптимальное произведение и выводит результат.

#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;

    if (N == 1) {
        cout << 1 << endl;
        return 0;
    }

    long long power = 1;

    if (N % 3 == 0) {
        for (int i = 0; i < N / 3; i++) {
            power *= 3;
        }
    }
    else if (N % 3 == 1) {
        power = 4;

        for (int i = 0; i < (N - 4) / 3; i++) {
            power *= 3;
        }
    }
    else {
        power = 2;

        for (int i = 0; i < (N - 2) / 3; i++) {
            power *= 3;
        }
    }

    cout << power << endl;

    return 0;
}

Использование типа long long позволяет хранить более крупные целые числа, чем тип int. Это важно, поскольку произведение нескольких троек быстро увеличивается.

7.5. Случай, когда N делится на 3

if (N % 3 == 0) {
    for (int i = 0; i < N / 3; i++) {
        power *= 3;
    }
}

Если число N делится на 3 без остатка, все головы можно распределить между драконами по три головы.

Например, если N = 9, программа выполняет три умножения на 3:

1 × 3 = 3;

3 × 3 = 9;

9 × 3 = 27.

В результате программа выводит 27.

7.6. Случай, когда остаток равен 1

else if (N % 3 == 1) {
    power = 4;

    for (int i = 0; i < (N - 4) / 3; i++) {
        power *= 3;
    }
}

Если остаток от деления на 3 равен единице, одна тройка вместе с оставшейся единицей заменяется двумя двойками.

Например, при N = 7 используется разбиение:

2 + 2 + 3 = 7.

Произведение равно:

2 × 2 × 3 = 12.

Переменная power первоначально получает значение 4, соответствующее произведению двух двоек. После этого программа умножает результат на 3 для каждой оставшейся тройки.

7.7. Случай, когда остаток равен 2

else {
    power = 2;

    for (int i = 0; i < (N - 2) / 3; i++) {
        power *= 3;
    }
}

Если остаток от деления на 3 равен двум, одна часть разбиения будет равна 2, а остальные головы распределяются по три.

Например, при N = 8 оптимальное распределение имеет вид:

2 + 3 + 3 = 8.

Сила стаи составит:

2 × 3 × 3 = 18.

7.8. Вывод результата

cout << power << endl;

После выполнения всех вычислений программа выводит значение переменной power. Оно соответствует максимальной силе, которую можно получить при заданном количестве голов.

9. Анализ эффективности алгоритма

Временная сложность алгоритма составляет O(N), поскольку количество итераций цикла пропорционально числу троек, на которые разбивается исходное число.

Дополнительная пространственная сложность составляет O(1), поскольку для решения используются только несколько переменных и не требуется создавать массивы или другие структуры данных.

Для заданного диапазона N < 100 алгоритм выполняется быстро и требует минимального объёма памяти.

Примечание о типе данных: для ограничений данной задачи результат помещается в long long. Для существенно больших значений N потребовалась бы проверка переполнения или реализация работы с большими целыми числами.
