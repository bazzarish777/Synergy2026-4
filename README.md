Кейс-задача №4. Драконья стая
1. Анализ условия задачи

Нам дано число N — общее количество голов всех драконов в стае.

У каждого дракона может быть от 1 до 7 голов.

Сила всей стаи определяется не суммой, а произведением количества голов всех драконов.

Например, если всего имеется 12 голов, можно распределить их так:

6 + 6 → сила 6 × 6 = 36;
4 + 4 + 4 → сила 4 × 4 × 4 = 64;
3 + 3 + 3 + 3 → сила 3 × 3 × 3 × 3 = 81.

Следовательно, необходимо найти такое разбиение числа N на числа от 1 до 7, при котором произведение будет максимальным.

2. Выбор алгоритма

Для решения задачи был выбран алгоритм динамического программирования.

Создается массив:

dp[i]

где dp[i] означает:

максимальная сила стаи, которую можно получить, если суммарное количество голов равно i.

Например:

dp[5] = 6

означает, что для пяти голов максимальная сила равна 6.

Это достигается распределением:

5 = 2 + 3

и силой:

2 × 3 = 6
3. Начальное состояние

Для начала устанавливаем:

dp[0] = 1;

Почему именно 1?

Потому что при построении произведения единица является нейтральным элементом:

1 × x = x

Это позволяет корректно рассчитывать последующие состояния.

4. Перебор количества голов одного дракона

По условию один дракон может иметь максимум 7 голов.

Поэтому для каждого значения i мы проверяем:

1 голова
2 головы
3 головы
4 головы
5 голов
6 голов
7 голов

если соответствующее количество не превышает i.

В программе это реализовано:

for (int heads = 1; heads <= min(7, i); ++heads)

Таким образом, ограничение из условия задачи непосредственно учитывается в алгоритме.

5. Формула динамического программирования

Если последний дракон имеет heads голов, то оставшиеся:

i - heads

голов должны образовывать стаю с максимально возможной силой.

Поэтому получаем:

dp[i - heads] × heads

Из всех вариантов выбираем максимальный:

dp[i] = max(dp[i], dp[i - heads] × heads)

Именно эта формула является основной частью решения.

6. Пример работы алгоритма

Рассмотрим, например, N = 10.

Возможные варианты разбиения:

10 = 7 + 3
7 × 3 = 21

10 = 6 + 4
6 × 4 = 24

10 = 5 + 5
5 × 5 = 25

10 = 4 + 3 + 3
4 × 3 × 3 = 36

10 = 3 + 3 + 2 + 2
3 × 3 × 2 × 2 = 36

Максимальное значение:

36

Поэтому программа для входного значения:

10

выдаст:

36
7. Почему ограничение в 7 голов не мешает найти оптимум

Интересный момент заключается в том, что хотя по условию дракон может иметь до 7 голов, оптимальное разбиение для больших N обычно состоит преимущественно из троек.

Например:

15 = 3 + 3 + 3 + 3 + 3

Сила:

3⁵ = 243

А вариант с семёрками:

15 = 7 + 7 + 1

даёт:

7 × 7 × 1 = 49

Поэтому ограничение 7 учитывается в алгоритме, но на практике оптимальное решение чаще использует 2, 3 и 4 головы на дракона.

8. Реализация программы

Готовая программа на C++17:

#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    int N;
    cin >> N;

    vector<long long> dp(N + 1, 0);

    dp[0] = 1;

    for (int i = 1; i <= N; ++i) {
        for (int heads = 1; heads <= min(7, i); ++heads) {
            dp[i] = max(dp[i], dp[i - heads] * heads);
        }
    }

    cout << dp[N] << '\n';

    return 0;
}

10. Оценка сложности алгоритма

Максимальное значение N по условию меньше 100.

Для каждого i перебирается не более 7 вариантов количества голов дракона.

Поэтому количество операций примерно:

N × 7

То есть временная сложность:

O(N × 7) = O(N).

Память:

O(N),

поскольку используется массив dp размера N + 1.

12. Итоговый вывод

В ходе выполнения кейс-задачи была разработана программа для нахождения максимально возможной силы драконьей стаи при известном общем количестве голов.

Для решения использован метод динамического программирования. Для каждого количества голов от 1 до N программа рассматривает все допустимые варианты количества голов последнего дракона — от 1 до 7. Для каждого варианта вычисляется произведение силы уже рассчитанной части стаи на количество голов последнего дракона. Из полученных значений выбирается максимальное.

Таким образом, программа позволяет найти оптимальное распределение N голов между драконами и соответствующее ему максимальное произведение. Алгоритм имеет временную сложность O(N) и требует O(N) памяти.
