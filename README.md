# Кейс-задача №4 — Драконья стая

Дано N голов, причем у одного дракона может быть от 1 до 7 голов.
Сила стаи равна произведению количества голов всех драконов.
Нужно получить максимальную возможную силу.

## Алгоритм

Используется динамическое программирование.

`dp[i]` — максимальная сила стаи с суммарно `i` головами.

Для последнего дракона перебираем `heads` от 1 до 7:
`dp[i] = max(dp[i], dp[i - heads] * heads)`.

Начальное значение: `dp[0] = 1`.

## Сложность

Время: O(N * 7), то есть O(N).
Память: O(N).

## Пример

Ввод:
`10`

Вывод:
`36`

Поскольку `10 = 3 + 3 + 4`, максимальная сила равна `3 * 3 * 4 = 36`.
